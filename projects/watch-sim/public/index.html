LED watch simulator

A 38 mm round watch board: 72 LEDs as hands, driven by the watch's own firmware code.

A simulation of the firmware logic, not of the electronics. The firmware's C code (UI, timekeeping, clock face, LED map, tilt, battery) runs here compiled to WebAssembly; only the chip's hardware layer is replaced by a simulated one. There is no current, brightness or battery-life model.

Controls

Press and hold. Tap A to show the time. Hold A + B for … to set the time: A steps the hour, B the minute (hold B to repeat). Keys: A, B.

Changing the angle is the motion that wakes the watch; it shows the time when the wrist ends up face up and level. 90° = arm hanging down.

Below … the watch stays dark except a short blink at 12. This only sets the voltage the firmware reads; it is not a battery model.

The watch has no idea what time it is after power-up: it starts in set mode at 12:00 for …, then goes to sleep. Use A and B to set the time.

Faster speeds only make the sleeping clock run faster.

What is real and what is simulated
  • Real firmware code: ui.c, timekeep.c, clockface.c, led_map.c, tilt.c, battery.c, unmodified.
  • Replaced by simulation: the hardware layer (main.c, twi.c, lis2dh12.c): timers, sleep, pins, ADC, the accelerometer and the buttons.
  • Not modelled: LED currents, brightness in the real world, battery capacity or life, crystal drift, contact bounce, EMC. LED glow here only shows each LED's share of the scan frame, scaled up so it is visible on screen.
  • Board: positions come from the PCB layout; part shapes are simplified boxes, not the real 3D models.
  • All numbers on this page (timeouts, thresholds, LED counts) are read from the firmware headers at build time.
